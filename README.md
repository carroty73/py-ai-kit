# py-ai-kit

책 "강사를 위한 파이썬 AI 수업 키트"의 학생용 예제 코드입니다.
파이썬 기초에서 시작해 모방학습, 강화학습으로 미로와 슈팅 게임을 가르치는 수업에서 씁니다.

> 준비 중입니다. 폴더 뼈대만 있고, 코드는 장별로 실행을 확인한 뒤 채웁니다.

## 받는 법

git을 몰라도 됩니다.

1. 이 페이지 위쪽의 초록색 **Code** 버튼을 누릅니다.
2. **Download ZIP**을 누릅니다.
3. 받은 파일의 압축을 풀고, VSCode에서 **폴더 열기**로 엽니다.

git을 아는 분은 `git clone`을 써도 됩니다.

## 폴더 지도

폴더 이름은 책의 부와 장 번호를 따릅니다. 장 번호는 부마다 1장부터 다시 셉니다.

| 폴더 | 책 |
|---|---|
| `part1_python/ch01_setup` ~ `ch06_classes` | 1부 파이썬 기초 1~6장 |
| `part2_imitation/ch02_maze_records` | 2부 2장 미로 기록 모으기 |
| `part2_imitation/ch03_knn` | 2부 3장 모방학습 |
| `part3_rl/ch02_maze_qlearning` | 3부 2장 Q러닝으로 미로 찾기 |
| `part3_rl/ch03_shooter` | 3부 3장 슈팅 게임 만들기 |
| `part3_rl/ch04_shooter_qlearning` | 3부 4장 슈팅 게임에 Q러닝 붙이기 |

2부 1장과 3부 1장은 코드 없는 수업 장이라 폴더가 없습니다.

## 준비물

파이썬, VSCode, 그리고 아래 라이브러리가 필요합니다. 설치 방법은 책 1부 1장을 따릅니다.

```
pip install pygame numpy scikit-learn
```

## 지켜 주세요

- 예제 파일은 같은 폴더에서 실행합니다. 일부 파일은 같은 폴더의 다른 파일을 불러옵니다.
- 실행하면 기록 파일(`*.csv`)과 학습 결과(`*.joblib`)가 생깁니다. 저장소에 올리지 않도록 `.gitignore`에 넣어 두었습니다.
